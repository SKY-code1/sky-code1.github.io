制作过程

两个作品，同一种笨办法

/// 先做完，再做好

真正花时间的不是把界面画出来，而是那些“看起来已经做完了、一用就露馅”的问题。 两件作品各挑四个最典型的坑，放在一起看。

01桌面整理器四个返工 →
  1. 最初 图标根本移不进分组

    分组框画出来了，但把文件拖进去没有任何反应——等于只有一个空壳子。

  2. 之后 移进去了，双击却打不开

    图标显示在框里，双击毫无反应；看起来“能用”，实际用户第一时间就会撞上。

  3. 再之后 按「显示桌面」，分组全被收走

    它本来就要一直在桌面上，却跟普通窗口一样会被收起来。

  4. 最后 在我电脑上能跑，别人装不上

    要装 .NET、缺文件、没有卸载——从“自己能用”到“能交给别人”。

02玉楼问命完整六个阶段 →
  1. 最初 旧版只在我自己的环境里跑

    换台电脑，Key、Redis、Qdrant 任何一样不成立，它就打不开。

  2. 之后 节气边界差一天，年月柱全错

    按 2 月 4 日估算立春，16:26 前后出生的人会差一整柱。

  3. 再之后 大模型把「偏弱」说成「极旺」

    让它自由解读，它会补出命盘里没有的信息，用户还看不出来。

  4. 最后 作品集放不了 Python 后端

    把推演搬进浏览器，才能做到打开网页就能用。
